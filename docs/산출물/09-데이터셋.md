### 1.2 원칙

1. **공식 출처 우선**: 라이선스와 이용 조건은 원 저장소 LICENSE, 공식 문서·약관 페이지에서 확인한다.
2. **최소 수집**: 대규모 코퍼스 대신 스택에 맞는 소량의 선별 데이터만 쓴다 (서비스는 모델을 학습시키지 않는다).
3. **고정과 재현**: 외부 저장소는 커밋 SHA를 고정하고 원본은 저장소에 넣지 않는다 (`data/raw/` gitignore).
4. **비밀 정보 제거**: 분석 전 `.env`·키 패턴을 제거한다 (NF-05).
5. **누수 방지**: 평가 데이터는 개발에 쓰지 않는다 (5절).

| 평가 세트 변경 | 결과가 나쁘다고 평가 저장소를 바꾸면 결과 왜곡 | 변경 시 7절 변경 이력에 사유 기록, 변경 전후 결과 모두 보고 |
| 시연·평가 혼동 | 시연용으로 다듬은 결과를 평가 결과로 제시 | 시연 저장소는 eval에 넣지 않고 보고서에서 구분 |

## 6. 런타임 분석 데이터(사용자 코드) 정책

- **고지·동의**: 분석 요청 화면에서 "주요 파일이 Google Gemini(무료 등급)로 전송되며, 무료 등급 입력은 모델 개선에 쓰일 수 있다"를 고지하고 동의를 받는다. 비공개·민감 코드는 올리지 말라고 안내한다.
- **비밀 정보 제거**: `.env`, 키 파일, 키 패턴(`AIza…`, `sk-…`, 개인 키 등)을 전송 전에 제거한다 (NF-05).
- **최소 보관**: 원본 zip과 압축 해제 폴더는 분석 후 즉시 삭제하고, 설명에 쓴 주요 파일만 `analysis_files`에 저장한다.
- **삭제**: 분석 삭제(F-19), 회원 탈퇴(F-03) 시 관련 파일·결과를 삭제한다.
- **비공개 기본**: 분석은 기본 비공개이며 사용자가 공개를 선택해야 피드·게시글에 노출된다 (F-19).
- **제출·평가 제외**: 사용자 코드는 개발·평가·제출에 쓰지 않는다. LLM 사용량(`llm_usage_logs`)은 집계 통계로만 보고한다.
