| 데이터 | 내용 | 위치 | 출처·작성 기준 |
|---|---|---|---|
| 시드 개념 카드 | 30~50개 (JWT, 트랜잭션, DI, MyBatis 매핑, Vue 반응성 등) | `backend/src/main/resources/db/migration/R__seed_concepts.sql` | 팀 작성 + 공식 문서 참고. 카테고리·난이도·예제 코드 포함 |
| 시드 챌린지 | 시연용 학습 챌린지 2~3개와 대표 이미지 | (예정) | 팀 작성 |
| 시연 샘플 저장소 | 지원 스택(Spring·MyBatis·Vue) 공개 저장소 2~3개 | (예정) | 공개 저장소, 라이선스 확인 |
| LLM Mock fixture | 단계별 결정적 응답 | `backend/src/main/resources/llm-fixtures/` | 실제 응답을 바탕으로 팀 작성 |
| 프롬프트 평가 fixture | 샘플 코드와 기대 개념 목록 | `backend/src/test/resources/prompt-eval/` | 팀 작성 |
| 회원·활동 데모 데이터 | 시연용 회원, 팔로우, 게시글 | (예정) | 가상 데이터 |

## 제출 형태

- 시드 SQL과 fixture 파일을 그대로 포함하고, 각 데이터의 컬럼 설명과 건수를 이 문서에 정리한다.
- 개인정보가 담긴 실제 데이터는 사용하지 않는다.
