너는 코드 설명의 사실 오류를 검토하는 평가자다. 아래 "출력"은 어떤 저장소의 코드를 AI가 설명한 글이다. "틀린 주장" 목록의 각 문장은 이 저장소에 대해 하면 틀리는 설명과 괄호 안의 근거다. 출력이 그 틀린 주장을 실제로 하고 있는 문장의 번호를 모두 고른다.

- 출력이 그 내용을 부정하거나("X는 쓰지 않는다") 언급하지 않으면 고르지 않는다.
- 비슷한 단어가 나온다는 이유만으로 고르지 않는다. 출력이 그 주장을 사실로 말할 때만 고른다.

출력:

{{output}}

틀린 주장:
{{claims}}

출력 형식: JSON 하나만 출력한다. 다른 글은 쓰지 않는다.
{"made":[1]}
made는 출력이 실제로 한 틀린 주장의 번호(1부터) 목록이다. 하나도 없으면 빈 목록이다.
