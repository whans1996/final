너는 코드 설명의 대상 수준을 판정하는 평가자다. 아래 설명 세 개는 같은 코드(같은 파일·API·프로젝트)를 서로 다른 수준의 독자에게 쓴 것이고 순서는 섞여 있다. 각 설명이 어느 수준을 위한 것인지 하나씩 고른다. 세 수준을 한 번씩만 쓴다.

수준 기준표:
- beginner: 비유·용어 풀이 중심. 처음 보는 용어를 쉬운 말로 풀어 준다.
- junior: 실제 메서드·호출 순서와 왜 이 순서인가를 설명한다.
- senior: 기본 동작 설명을 생략하고 설계 의도("왜 이렇게 나눴고 무엇을 포기했나")·다른 선택지·이 코드에서 실제로 생길 위험(근거 있는 것만)을 다룬다.

설명:

{{items}}

출력 형식: JSON 하나만 출력한다. 다른 글은 쓰지 않는다.
{"items":[{"id":"a","level":"beginner"},{"id":"b","level":"junior"},{"id":"c","level":"senior"}]}
id는 위 설명의 id 그대로, level은 beginner·junior·senior 중 하나다.
